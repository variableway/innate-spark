# Multiple LLM Provider

当前现状：
1. 有多个LLM供应商，如OpenAI、Google Cloud AI等。
2. 但是使用工具的时候需要打开很多不同的工具
3. 当前想使用一次配置可以全部工具都可以使用
3. 同时有些API Key 可能都只能在Claude Code上使用，这样也就是Claude Code或者Open Code可能需要配置不同的LLM Provider
4. LLM Provider 可以使用不同的模型，也就是不同模型选项需要在不同的AI Agent中使用
