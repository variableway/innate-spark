# README 

这个项目是用来收集数据到本地的：
1. 把website转换成markdown保存
2. 把website clone下来，或者获取所有的css theme
3. 可以批量收集数据和网站
4. 可以获取一些类似飞书文档这样的内容，可以放置到网盘比如夸克，或者ima等等
5. 一定有skill在支持workbuddy等AI Agent

## Task 1: 从HTML-MARKDOWN 开始

1. 实现需要收集有Top 10的类似SKILL
2. 获取这些SKILL是如何实现的的
3. 然后开始自己整理实现这些内容
4. 所有的相关文档需要写入到clone-them目录：
    1. tasks： 所有的任务
    2. docs： 所有的实现文档
    3. research: 分析和调研文档

先办任务转换为Task然后保存记录之后，把调研文档写入当前目录research，tasks和research目录需要按照task分子目录
