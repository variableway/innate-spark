Profile

You might say

Configure two profiles for me: 'work' using our company's private API, and 'personal' using my own API Key. Show me how to switch between them.

A named and saved collection of configuration settings for switching between work, personal, or different provider environments.·For example, work and personal projects may use separate Providers, Base URLs, key variable names, or permission settings saved as work and personal profiles. Selecting a profile loads its configuration; it does not switch git branches, project files, or conversation history, and it does not replace checking the actual endpoint and credential source.

A Profile isolates configuration; it does not create a new session. Sessions and configuration are different concepts.

What does a Profile do?

It names a settings group: Related Provider, Base URL, model, and permission settings can be saved as one named combination.

Select one at startup: When the tool starts with an explicit profile, the client initializes the session from that group.

It reduces manual switching errors: Separate work and personal connections reduce the chance of sending code through the wrong endpoint.

What people often confuse

A Profile is not a workspace, Git branch, or Session. It changes the AI client's connection settings, not local files, commit history, or conversation context.
