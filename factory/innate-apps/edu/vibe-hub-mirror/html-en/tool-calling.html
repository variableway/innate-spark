How a tool request becomes a real result

Request execution based on tool definitions: Tools are defined with a name, description, and typed parameters. The model fills parameters to request a tool call, but this is only an invocation request—the model does not run the tool directly.

The application validates permissions and parameters: It checks whether the tool is permitted, whether parameters make sense, and whether the user has access.

Real execution results return to the model: Only the executed result from the external tool comes back to the model to formulate the final answer.

What people often confuse

Data-shaped parameters are not permission to act. Delete and send actions still need scope checks and confirmation.
