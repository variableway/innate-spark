Token

You might say

Everyone says AI pricing is based on tokens. What is a token, and how does it relate to what I type?

A small piece of text or code that a model reads and writes·Models split text, punctuation, and code into tokens using their own rules. Input and output token counts affect available context, wait time, and cost; a token is not always one word or one character.

How text becomes pieces a model processes

Split into rule-based pieces: The model breaks sentences into tokens using its tokenizer. English is roughly 1 token per word; Chinese is around 1.5–2 tokens per character.

Generated piecewise, counted both ways: It reads input pieces and generates output pieces one at a time. Both your prompt and the generated response count toward token usage.

Keep files relevant to protect quality and budget: A webpage's source is roughly 2,000–5,000 tokens. Sending only relevant files instead of entire projects saves cost and avoids diluting model focus.

What people often confuse

One Chinese character is not guaranteed to be one token. Use the target model’s tokenizer for an exact count.
