IP Address

You might say

Why can I open the page on my computer but others cannot?

The numeric address of each device on the internet, used to route data to its destination·Local development addresses like 127.0.0.1 or localhost point exclusively to your current machine, paired with a port for each service. When a site works locally but fails on a coworker's device, you have likely shared a loopback address instead of a LAN or public IP; public deployment is required for open internet access.

Who can reach each kind of address
localhost:3000
127.0.0.1 · Only this machine can reach it

localhost means this very computer; a colleague using this address reaches their own machine.

Listening scope and address type are separate: if the service listens on localhost only, the LAN address fails too.

Address scope decides who can reach it

127.0.0.1: only this machine: localhost and 127.0.0.1 mean this very computer; anyone else using the address reaches their own machine.

LAN address: reachable inside one network: Addresses like 192.168.x.x and 10.x.x.x work within the same LAN; devices outside cannot reach them.

Public address: anyone can reach it: Deployed services use public addresses; a domain is just a name resolved to an IP before access.

What people often confuse

Listening address and access address are two things: if the service listens on localhost only, even giving a colleague the LAN address fails. When others cannot reach it, check the listening scope first, then the address type.
