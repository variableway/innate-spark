Permission Mode

You might say

Routine changes inside this project can continue automatically, but ask before deletion, wider access, or external actions. Which permission setting fits?

A set of control presets defining file system boundaries, network access limits, and user confirmation triggers for an AI agent.·For example, one Codex permission option can allow routine reads, writes, and local commands inside the current workspace, then ask before network access or crossing that boundary. Names and combinations differ across tools. Check the sandbox scope, when prompts appear, and who reviews them before choosing.

Separate sandboxing from approvals

The sandbox determines which files, networks, and system resources commands can access; the approval policy determines when an action pauses to ask. A product may combine both into one permission option, but approving an action does not automatically widen the sandbox, and fewer prompts do not mean there is no access boundary.
