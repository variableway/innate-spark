Typography≠Heading

Typography is the full system of text roles and styles, including headings, body copy, and supporting text. A heading is only one text role that marks page or section hierarchy.

When to use it

  • Create clear levels for page, section, and item headings
    Page titleSection title
  • Keep long body text comfortable to read
    Body text needs a readable size and line height for long-form reading.
  • Make dates, notes, and other supporting details quieter
    Website redesign v2In progress
    Alex Chen updated 3 days ago · visible only to you
  • Emphasize a small number of truly important words
    This update fixed 12 issues; the payment flow changed the most, so test it carefully.

When NOT to use it

  • Use so many heading styles that the hierarchy disappears
    Heading 1Heading 2Heading 3Heading 4Heading 5
  • Set body text too small or too light to read comfortably
    This is an important instruction, but it uses 10px light-gray text that’s hard to read.
  • Bold a whole paragraph when only one point needs emphasis
    When every word is bold, nothing reads as the real priority.
  • Use spaces and line breaks to force alignment; use Space
    Name: Alex Chen
    Phone: 138 0000 0000    Full-width spaces break alignment when the font changes
