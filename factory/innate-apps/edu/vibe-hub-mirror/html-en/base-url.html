Base URL

You might say

I've switched the model API endpoint to our team's self-hosted proxy. Where do I update the Base URL to make it work?

An address prefix shared by a group of API requests, onto which specific endpoint paths are appended.·For example, one client may combine https://openrouter.ai/api/v1 with /chat/completions to form the full request URL. Whether /v1 belongs in the prefix and which path the client appends depend on both the service and the client. Check both sets of official documentation instead of applying one fixed pattern.

How Base URL Works

Use a restaurant address to understand Base URL: Imagine the AI tool as someone placing an order for you. The Base URL is like the restaurant's address: it tells the tool where to send the request; it does not choose the model.

Where can you find the Base URL setting?: Codex: ~/.codex/config.toml; Claude Code: global ~/.claude/settings.json, project-level .claude/settings.json. If you use an environment variable, also check ANTHROPIC_BASE_URL.

A local service may use its own address: A local model may use http://localhost:11434/v1, which sends the request to your computer; it is not the same address as OpenRouter.

What else should you check after changing the address?

When troubleshooting a Base URL, check three things: the request address is correct, the service supports the model, and the API key came from that service.
