Header

You might say

How should the top bar be laid out? It needs to fit the logo, navigation, and sign-in button.

The top section of a page that introduces the site or page and often contains navigation·A Header usually holds the brand and the paths people need first, such as main navigation, search, or account access. It is broader than a Navbar, which is specifically the navigation portion.

Header≠Navbar

Header is the complete top page area and can include brand, search, and sign-in. Navbar is the portion dedicated to primary navigation.

When to use it

  • Use a page header when the brand, primary navigation, and account controls need to stay together at the top.
    ◆ BrandProductPricingSearch · Sign in
  • Documentation and ecommerce sites often need Search in the header.
    Documentation⌕ Search documentsSign in
  • Design the mobile header separately: keep the brand and primary actions, and move secondary links into a menu.
    ◆ Brand☰
  • Put temporary announcements above the header, and keep their purpose distinct from navigation.
    New version released · Check for updates
    ◆ BrandProduct Documentation Login

When NOT to use it

  • Cram every navigation link and action into the header, making important actions hard to find.
    Brand · Product · Solutions · Customers · Pricing · Docs · Blog · Events · Careers · Search · Sign in · Sign up
  • Make a fixed header so tall that it obscures content while the user scrolls.
    The fixed header takes up nearly half the screen.
  • Omit both a brand marker and a link home, leaving users unsure which site they are on.
    ProductPricingHelpSign in
  • Treat the page header and Navbar as the same thing. Distinguish them by the top-level container and their navigation role.
    ProductPricingDocs
