Navbar

You might say

Put the main sections in the top navigation, and make it clear which page I'm on.

Keep the brand, main destinations, and key action easy to reach·A website navbar helps visitors understand where they can go and how to return home. Keep the number of primary links manageable, show the current section when useful, and adapt the menu for smaller screens without hiding essential paths.

Navbar≠Header

Header is the complete top page area and can include brand, search, and sign-in. Navbar is the portion dedicated to primary navigation.

When to use it

  • Primary website navigation
    ◆ LogoProductPricingDocsStart for free
  • Brand and home link
    HomeProductDocsPricing
  • Access to sign in or a key action
    Navigation bar · Sticky
  • A compact menu that remains consistent across pages
    Product featuresPricingCustomer reviewsFAQ

When NOT to use it

  • Put every page in the top row
    DashboardProjectsTasksFilesMembersCalendarReportsMessagesSettingsTrash
  • Use labels that change between pages
    SaveDeleteExport
  • Hide important links only in a desktop hover menu
    ◆ Logo☰
  • Let a sticky navbar cover the content below
    HomeProductDocsPricing
    Nothing is highlighted—what page am I on?
