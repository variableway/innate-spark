Empty

You might say

When there's no data, show an image and tell people what they can do next instead of leaving the page blank.

Explain why no data is shown and what to do next·An empty state should not leave a blank area. Tell people what normally appears there, why it is empty now, and whether the next step is to create something, search, change a filter, or wait for data.

When to use it

  • A new account with no records
    NameStatus
    There’s no data here yet
  • Search with no results

When NOT to use it

  • Show only an illustration with no explanation
    No data
    User: What now? What should I do?
  • Blame the user for an empty result
    Loading, please wait…
  • Offer an action that cannot solve the empty state
    No data
    It’s actually a network error, but it looks empty
  • Use the same message for first use, errors, and no search results
    Nothing here yet
    The illustration steals attention from the content
