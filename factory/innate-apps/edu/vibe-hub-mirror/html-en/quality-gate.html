Quality Gate

You might say

Why is my Pull Request blocked with an error saying 'Quality gate failed'?

A set of conditions that decide whether code may be merged or a release may proceed·All tests may pass while coverage remains below the agreed 80%, keeping a pull request blocked. Checks produce results and the gate evaluates them; branch protection must require that result to enforce the merge restriction.

All 45 tests pass, but 68% coverage is below the agreed 80%, so the required check still fails.

How results become merge requirements

Agree on criteria, then enforce them: Set criteria according to project risk, such as passing critical tests and no severe security findings. CI runs checks; require the gate result in branch protection to block changes that fail.

Use the failure report to choose a fix: For low coverage, inspect untested paths; for failing tests, compare actual and expected results. Rerunning unchanged code or lowering the threshold does not prove that the original problem was fixed.

What this does not guarantee

Passing means the configured criteria were met, not that the software is defect-free. Installing a scanner alone does not block merges; deployment gates must likewise be connected to the release flow.
