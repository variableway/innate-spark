The button reads count. When count changes, React updates this button text with the new value.

How a state change updates a component

A component is an interface piece that accepts inputs: Buttons and cards can be separate components. Components receive external parameters (Props, like title or price) to control content, allowing the same UI structure to be reused across pages.

State holds the current value: A click changes a counter from 0 to 1; state is what this part should show now.

React recalculates the view: React recalculates the related component and the renderer updates the needed DOM.

What people often confuse

A component update is not a full-page reload. Requests, saved data, and URL changes are handled by other project code.
