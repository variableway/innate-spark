Textarea

You might say

People need to write a longer message here, so one line won't be enough.

Let the user enter several lines of text·Comments, descriptions, feedback, and prompts for AI often need a multiline textarea. Give it a useful starting height and, when needed, a character count or resize control. A normal Input is faster for short, single-line answers.
