Timeline

You might say

Show the shipping updates in time order so people can tell where the package is.

Show a sequence of events in time order·A timeline works for shipping, approval records, and release history. Choose whether the newest event appears first or last and stay consistent. Dates, labels, and status text carry the meaning; dots and colors only help people scan.

When to use it

  • Shipping progress
    Delivered · Today, 14:32
    In transit · Yesterday, 09:15
    Order placed · 2 days ago, 20:02
  • Approval history
    oil-oil approved the request
    Alex Chen submitted the request
    Created the approval request
  • Release notes
    v2.4 added dark mode
    v2.3 fixed 12 issues
    v2.2 launched collaboration
  • A record of events over time
    Deployment successful
    Building…
    Tests failed

When NOT to use it

  • Use a timeline for items with no meaningful order
    1Enter information2Confirm order3Complete payment
  • Switch time direction halfway through
    Weekly meeting today
    Lunch together at noon
    There’s no time sequence here; a regular list works
  • Rely on dot color without status text
    Feature A
    Feature B
    Feature C
    The items have no sequence, so a timeline doesn’t fit
  • Pack long, unrelated documents into each event
    Release announcement
    The nodes are too dense; use cards instead
