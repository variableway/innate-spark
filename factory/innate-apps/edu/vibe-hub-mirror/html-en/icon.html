Icon

You might say

Add a small icon to the button so people can tell what it does without reading.

A small, consistent visual symbol for an action, object, or status·Familiar icons such as search, download, and close help people scan quickly. For an unfamiliar or high-risk action, add text or a Tooltip.
⌕Search↓Download⚙Settings
Icon≠Image

Icon is a small reusable symbol for a function or concept. Image displays a photo, illustration, or content itself.

Icon≠Button

Icon communicates meaning. It becomes an icon button only when placed in a Button that runs an action.

When to use it

  • Common tool actions
    ⌕↓×Search · Download · Close
  • Compact toolbars
    ↶↷⌗⋯
  • Status cues with text
    ✓File synced

When NOT to use it

  • An unfamiliar action with only an icon
    ◈The icon’s meaning is unclear
  • Unrelated dangerous actions mixed under More
    ⋯Delete project is hidden under More
  • Emoji in place of consistent system icons
    ⬇📥⇩Three download icons with inconsistent styles
