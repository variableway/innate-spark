昨天你在第一轮会话中的交代：“在这个项目里，严禁擅自修改公共组件 Navbar.tsx。”关掉对话即失效
今天新开的会话 (Session 2)
你（不再重复说明旧约束）

请帮我在页面右上角加一个搜索框。

AI Agent

好的！我已经在公共组件 Navbar.tsx 里加入了搜索框。

❌ 昨天明明说过“不要改公共组件”，但新开会话后 AI 全忘了！你不得不每次都从头交代一遍。

约束放在对话里最容易遗忘；把团队约定写进项目规则文件（如 AGENTS.md），新对话才能稳定继承。

三个位置各自保留多久

对话里：本轮有效：只对当前这次对话生效；新开对话需要重新说明，忘记说约束就消失。

项目规则：随项目生效：写进规则文件或团队配置后，每次新对话都会加载；可检查、可共享，适合项目级约定。

记忆机制：跨会话保留：由 Agent 的记忆保存偏好和历史结论，跨对话仍记得；具体支持程度依产品而定。

容易混淆的地方

记忆不是上下文：上下文窗口限制一次回答能参考多少信息，记忆决定跨会话保留什么。偏好放对话里最灵活也最易忘，放规则里最稳。

选择题选择一个你认为最合适的答案
