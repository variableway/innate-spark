滑块Slider

你可能会说

价格范围想用一根可以拖着走的滑杆来调。

滑块是沿着一段连续或分级范围调整数值的表单控件·音量、亮度和价格区间可用滑块调整。应显示范围、当前值并支持键盘操作；需要精确输入 50 等具体数值时，还要提供 数字输入框 Number Input。
音量 亮度

什么时候用

  • 音量、亮度这类连续调节
    🔊60
  • 价格区间筛选：双滑块框定范围
    价格
    ¥100 — ¥300
  • 调节程度、强度：允许近似选择
    创作强度较强
  • 拖动时实时预览效果
    ☀

什么时候不用

  • 需要精确到个位：使用 数字输入框 Number Input
    需要精确数值时，应配合数字输入框
  • 只有少量固定档位：使用 单选框 Radio
    只有少量离散档位时，可直接列出选项
  • 范围跨度很大且难以拖到目标值：配合 数字输入框 Number Input
    2,431 / 100,000
    范围跨度过大，拖动难以定位目标值
  • 需要选择日期：使用 日期选择器 Date Picker
    7 月 12 日
    日期应使用日期选择器
