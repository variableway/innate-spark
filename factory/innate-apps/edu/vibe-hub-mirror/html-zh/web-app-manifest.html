清单描述安装和启动；它本身不保证离线可用。

Manifest 负责安装后的哪些信息

它集中描述应用身份和启动方式：name 影响安装后的名称，icons 提供系统图标，start_url 指定启动地址，display 影响打开时更像独立应用还是普通标签页。页面要通过 link 关联正确文件。

安装后结果才是验收证据：修改文件后要重新安装，检查名称、图标、启动路径和窗口形态。浏览器能打开网页，只能证明页面可访问，不代表这些安装信息正确。

它不等于完整 PWA 或 Favicon

Web 应用清单 Web App Manifest 描述 Web 应用的安装和启动信息；网站图标 Favicon 主要服务浏览器标签页和书签；离线缓存还需要其他运行机制。拥有 Manifest 不会自动保证离线可用。
