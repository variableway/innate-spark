主键Primary Key

你可能会说

AI 说按 id 更新这条记录，这个 id 是哪里来的？

一张表里用来唯一区分每一行的字段·修改单条数据或关联跨表记录时，必须依靠每行独一无二的主键来精准定位。姓名、邮箱或手机号可能发生重名或换绑，无法充当绝对锚点；更新与删除始终基于主键操作，才不会误伤其他数据行。

按 id 更新恰好影响一行；按邮箱更新会同时改到两行。

主键为什么必须是唯一的

定位一行，而不是一批：更新、删除时按主键指定，影响恰好一行；用可重复的字段定位会改到多行。

普通字段会重复：同名、同邮箱完全可能出现；主键的值不允许重复，也不允许为空。

表之间的关联靠它：订单表记录“属于哪个用户”时，存的就是用户表的主键，而不是姓名。

容易混淆的地方

主键保证唯一，不保证正确。出现两条看起来重复的数据时，先弄清为什么重复——可能是重复录入或迁移出错，而不是先删掉一条。
