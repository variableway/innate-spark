AI 基础7 个条目

AI 应用基础AI Application Basics

我想在自己的网站里，也加一个能聊天的 AI 助手。

AI 幻觉AI Hallucination

这份 AI 旅行攻略写得很肯定，但景点开放时间我不敢直接信。先帮我联网查官网或官方预约页，把来源链接和更新时间一起给我。

Vibe Coding

我不会写代码，就想用说话的方式让 AI 帮我把东西做出来。

多模态Multimodal AI

能不能让 AI 不光看文字，还能看懂我发的截图？

RAG

我想让 AI 只按我们公司的文档回答问题，怎么弄？

微调Fine-tuning

能不能训练一个只懂我产品的模型？

推理模型Reasoning Model

AI 想这么久，是在卡住吗？
上下文7 个条目

上下文工程Context Engineering

任务做久以后，AI 开始漏掉刚确认的要求。下一轮应该带上哪些资料？

Token

都说按 token 收费，token 到底是个啥？跟我打几个字什么关系？

上下文窗口Context Window

聊着聊着 AI 把开头说的忘了，是不是它有记性上限？

系统提示词System Prompt

我想给 AI 立规矩：什么语气、什么能答什么不能答，在哪设置？

对话历史Conversation History

聊天界面里明明还有前面的内容，AI 为什么还是答错了我说的第二条？

提示词Prompt

帮我做一个客户报价列表：字段是客户名、金额、日期、跟进状态，先存在浏览器本地，列表按时间倒序。

记忆Agent Memory

每次新开对话都要重说一遍要求，太烦了。
请求与输出4 个条目

无状态请求Stateless Request

聊天里明明有刚才的表格，为什么只发“继续”时 AI 还是不知道要做什么？

结构化输出Structured Output

AI 回的一大段话没法直接用，能不能按固定的格式给我？

流式响应Streaming Response

别让我干等，像打字机一样一个字一个字往外蹦。

温度Temperature

为什么同一个问题，AI 每次答得都不一样？
Agent 与工具7 个条目

AI Agent

我不想一步步指挥，能不能给个目标，让它自己想办法完成？

Agent 运行框架工程Harness Engineering

同一个 AI 有时做得很好，有时总在同一个地方犯错，除了换模型还能改什么？

人在回路Human-in-the-loop

攻略和机票可以让 AI 先查，但付款、出票前一定要让我确认。

Sub-agent

大任务能不能拆给几个帮手同时干，最后汇总给我？

工具调用Tool Calling

AI 光会说不会做，怎么让它真的去查数据库、发请求？

ReAct

AI 能不能每完成一步先检查结果，再决定下一步？

Agent 循环Agent Loop

检查失败以后，AI 应该继续修改、停下来问我，还是结束任务？
连接与配置7 个条目

模型提供方Provider

配置里的 Provider 和 Model 分别指什么？我的请求最后会发给谁？

服务基准地址Base URL

我把大模型的 API 地址换成我们团队自己部署的中转服务了，现在需要改哪里的 Base URL 才能生效？

API 代理 / 中转站API Proxy

我换成中转地址后请求能成功了，但提示词、文件和 Key 会经过谁？帮我把链路检查清楚。

OpenAI 兼容 APIOpenAI-Compatible API

我这个大模型工具只支持配置 OpenAI，但我想用 DeepSeek 的模型，是不是直接改一下 Base URL 和 API Key 就可以用？

API 密钥API Key

帮我接上大模型 API，把 API Key 放在环境变量中读取，千万不要硬编码在代码里。

配置文件Configuration File

帮我把 AI 工具的配置文件里默认的模型换成 DeepSeek，并且把超时限制设置成 60 秒。

配置档案Profile

帮我配置两个 Profile：一个叫 work 用我们公司的内网 API，一个叫 personal 用我自己的 API Key，并告诉我怎么切换它们。
规则与扩展5 个条目

项目规则Project Rules

每次都要提醒 AI 使用 TypeScript 和项目现有样式，有办法把这些要求放进项目规则吗？

生命周期钩子Hook

这个工具支持写入后 Hook 吗？如果支持，让它只格式化刚改过的文件。

插件Plugin

AI 插件、Hook 和 Skill 都像扩展，这个需求到底该用哪一种？

MCPModel Context Protocol

能不能让 AI 接上工单系统，帮我查 #1024 是谁负责的？

Skill

同一个任务每次都要重新教一遍，能不能让它记住这套做法？

权限模式Permission Mode

沙箱Sandbox

提示词注入Prompt Injection
