后端 VibeCoding 术语

网络与地址12 个条目

域名Domain

我想让别人输入一个好记的名字，就能打开我的网站。

DNS

买了名字为什么还要“解析”？帮我把名字指到我的服务器上。

URL

地址栏里那一长串是什么？我想让每个页面都有自己固定的地址。

HTTP

我就想知道，点一下按钮，浏览器和服务器之间到底发生了什么。

Cookie

登录成功但一刷新就退出，帮我检查会话 Cookie 有没有被设置和随请求带回去。

HTTPS

浏览器说我的网站“不安全”，地址栏那个小锁怎么弄出来？

CDN

外地用户说图片加载慢，能不能让他们从就近的地方下载？

端口Port

本地项目跑在 3000 端口，接口服务在 4000；帮我确认浏览器连的是哪一个。

重定向Redirect

旧的活动链接要带到新版页面，别让用户打开后直接看到 404。

HTTP 状态码HTTP Status Code

页面打开是一片 404 页面，是链接写错了还是没部署好？

IP 地址IP Address

为什么我电脑上能打开，别人打不开我的页面？

WebSocket

聊天室怎么实时收到别人的新消息？
接口与数据9 个条目

API

我的网页想从后台拿数据，听说要有个什么“接口”，到底是啥？

JSON

AI 返回给我的那种大括号套小括号的数据，怎么读、怎么写？

CORS

网页请求接口被浏览器拦住了，帮我检查是不是 CORS 配置没有允许这个站点。

数据校验Validation

用户乱填也能提交成功，怎么在保存之前先拦住？

入队Enqueue

上传以后先别让页面一直等，把转码任务放进队列并返回任务 ID，之后能查到处理状态。

幂等Idempotency

支付回调可能重复送达，但同一个订单只能标记支付成功一次，重复回调要返回已处理结果。

消费者（消息队列）Message Consumer

消息已经发出去了，但队列一直增长。帮我确认有没有消费者在接收、处理并确认这些消息。

Webhook

支付成功后自动开通权限，怎么实现？

HTTP 方法HTTP Methods

AI 说这里应该用 POST 而不是 GET，什么意思？
数据库9 个条目

浏览器存储Browser Storage

刷新页面后保留这个草稿，但不要把它当成所有用户共享的数据库。

数据库Database

用户发的内容刷新就没了，得找个地方真正存下来。

数据库迁移Database Migration

用户表里已经有真实数据了，我要再加一个必填状态字段，应该按什么顺序改才不会让旧数据立刻报错？

SQL

我想查出“最近 7 天下单的用户”，那句话怎么写？

事务Transaction

创建订单和扣库存必须一起成功，任何一步失败都不能留下半个订单。

写入数据库Database Write

接口说保存成功，但刷新后昵称又没了；请确认这次修改真的写进数据库并提交了。

PostgreSQL

AI 推荐我用 Supabase 和 PostgreSQL 存用户和订单，它和普通存文件有什么区别？

对象存储Object Storage

用户上传的头像到底存到哪里？

主键Primary Key

AI 说按 id 更新这条记录，这个 id 是哪里来的？
后端开发14 个条目

后端Backend

用户看不见的那部分在哪跑？登录、存数据这些事是谁干的？

后端框架Backend Framework

写后端有没有现成的架子，别让我从零搭。

路由与端点Route & Endpoint

用户访问不同的网址，怎么让不同的代码来接管？

原子性Atomicity

两个用户同时抢最后一件时，不能出现两张成功订单；检查和扣库存要作为一个整体。

进程Process

图片处理一崩，整个网站也跟着停了。把这类任务放到独立进程，并验证主服务还能响应。

线程Thread

两个请求会同时改同一份缓存。先确认它们是不是同一进程里的线程，并把共享状态的访问顺序处理清楚。

协程Coroutine

接口在等外部服务时不要把整条执行路径堵住，让协程在等待处挂起，先处理其他请求。

消息队列Message Queue

导出大报表要等很久，能不能先给我一个任务编号，让后台慢慢生成，并在页面上看到等待、处理中、完成或失败？

副作用Side Effect

用户只是在预览价格，不能悄悄写入订单或发邮件；真正提交时再明确执行这些动作。

锁Lock

两个请求同时扣最后一件库存时，只能让一个先改。请给共享记录加锁，并验证另一个会等待后重新检查。

竞态条件Race Condition

优惠券偶尔会超发，但单次测试又正常。请按并发时序复现这个竞态条件，再修复并重复验证。

背压Backpressure

下游处理不过来时不要让队列和内存一直涨，帮我让上游自动放慢并能在恢复后继续。

租约Lease

两个调度实例不能同时跑同一份汇总；让一个实例限时持有，失联后过期，再由另一个接管。

分布式系统Distributed System

订单、库存和支付分在不同服务里，某个服务或网络断了时，系统还要知道这次订单到底走到哪一步。
账号与权限6 个条目

身份认证Authentication

怎么证明“你是你”？我要加登录功能。

权限控制Authorization

登录之后还要分谁能看谁不能看，管理员和普通用户不一样。

审计日志Audit Log

管理员改了谁的权限？我想知道谁在什么时候改了什么，结果是成功还是被拒绝。

功能权益Entitlement

用户买了高级版会员，代码里该怎么判断他能不能用这个导出功能？

会话Session

登录后刷新页面，为什么还保持登录？

OAuth 第三方登录OAuth

页面上放个“用微信登录”按钮，怎么弄？
上线与排错23 个条目

缓存Cache

新样式已经发布，但有些人还看到旧版，帮我查清到底是哪一层缓存没有更新。

SEO

帮我把这篇产品说明的标题、正文层级和链接改清楚，让搜索引擎和读者都看得懂。

规范网址Canonical URL

商品的广告参数地址仍要能打开，但请把无参数地址声明成规范 URL，并让 Sitemap 使用同一个地址。

XML 站点地图XML Sitemap

新文章已经上线但还没有多少内部链接，帮我生成只包含有效主地址的 sitemap.xml。

Robots.txt

请让爬虫少抓重复筛选路径，但不要把 robots.txt 当成管理页的访问权限。

找不到页面Not Found Page

这个文章地址已经不存在了，帮我做一个真正返回 404、还能回到文章列表的页面。

环境变量Env Var

密钥不能直接写进代码里，那应该放哪？

部署上线Deployment

我做好了，怎么才能让别人用一个网址就能打开我的页面？

网站托管Web Hosting

请确认这个项目有能持续提供网页的托管环境，再部署到公网，不要把 localhost 当成已经上线。

持续交付 / 持续部署CD

检查通过的版本先送到测试地址；正式发布前保留人工确认，除非团队明确要自动发布。

预发布环境Staging

先把候选版本部署到和生产配置接近的预发布环境，用脱敏数据走完流程，别直接碰生产。

监控Monitoring

上线后盯住错误率和请求延迟，超过阈值就告警，并标出是哪个版本开始异常。

回滚Rollback

新版本让预订失败率升高，先切回上一版，并确认版本号和错误率真的恢复。

功能开关Feature Flag

新行程编辑器先只给内部同事看，出问题时不用重新部署就能立刻关闭。

金丝雀发布Canary Release

先让 5% 用户使用新版本，错误率正常再逐步扩大，异常就立刻退回稳定版。

蓝绿部署Blue-Green Deployment

先让蓝色环境继续服务，在绿色环境部署并验收新版本，通过后再切生产流量。

Serverless

我就一个小功能，不想买服务器也不想运维，有没有按次跑代码的？

服务端日志Server Logs

线上报错了，我想知道服务器那边到底发生了什么，去哪看？

熔断器Circuit Breaker

支付依赖连续超时后别让所有请求继续等，先快速失败或降级，过一会儿再探测它是否恢复。

单实例部署Single-Instance Deployment

这个服务先只跑一个实例，重启时会短暂不可用；请把内存里的任务风险和可持久化的数据分开说明。

多实例部署Multi-Instance Deployment

把这个服务跑成多个实例分担请求，但用户换到另一个实例也要保持登录，不能只把进程数量加上去。

报错与调用栈Stack Trace

终端里报了一大段错，我该把哪一行发给 AI？

超时Timeout

点了保存一直在转圈，等了半分钟才说超时，是网不好还是服务器坏了？
