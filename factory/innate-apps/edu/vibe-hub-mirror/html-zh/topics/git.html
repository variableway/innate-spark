Git VibeCoding 术语

Git15 个条目

Git

AI 把我的代码改崩了，我想回到上一个能用的版本。

提交Commit

帮我把现在改好的代码存一下，我怕等下越改越乱，回不去了。

分支Branch

我想试试另一种做法，但又怕把现在这个能跑的版本搞坏。

合并Merge

我在另一边试的功能成了，怎么把它并回正式版本？

拉取Pull

同事说他改完了，我怎么把他那版拿到我电脑上？

推送Push

我本地改好了，怎么传到 GitHub 上让别人也能看到？

克隆Clone

给我一个项目网址，我想把整套代码下载到自己电脑上改。

合并请求Pull Request

我改完了，想请人看一眼没问题，再合进正式版本。

工作树Worktree

功能改到一半突然要修紧急 bug，我又不想收拾现在这个现场。

贮藏Stash

改到一半要切去干别的，先把现在这些东西临时收起来。

忽略文件.gitignore

有些文件我不想让 Git 管，比如密钥和依赖包，怎么排除掉？

差异对比Diff

帮我看看这次到底改了哪几行，加了什么、删了什么。

代码冲突Merge Conflict

拉取新版本后 Git 停下来说有冲突，我该打开哪个文件、改哪一段？

远程仓库Remote Repository

我的提交只在自己电脑上，怎么让别人也能看到？

重置与回退提交Reset & Revert

刚才提交错了，怎么把它撤掉？
