结构化输出Structured Output

你可能会说

AI 回的一大段话没法直接用，能不能按固定的格式给我？

结构化输出是要求 AI 按事先约定的栏目和格式返回结果的方式。·例如可把邮件整理成包含日期、地点和标题的一组固定信息，供表单或日历直接读取。格式正确不代表内容真实可用，日期、金额等信息仍要检查。

邮件内容怎样变成可校验字段

先定结构：产品指定标题、日期、地点等字段；schema 写清字段名、类型和必填项。

按约定返回数据：模型按这个结构返回数据；这里用 JSON 表示，但也可以有其他受约束的数据形式。

再做业务检查：产品还要确认日期可解析、地点有效，才写入日历或继续下一步。

容易混淆的地方

JSON 只是数据的编码形式；即使格式和 schema 都通过，也不说明邮件里的日期和地点一定真实可用。
