配置文件是用文件保存的软件设置，供程序在启动或运行时读取。·例如 AI 工具可以从配置文件读取模型、连接地址、超时和权限设置，而项目规则文件负责说明当前项目的技术栈和协作要求。配置文件可能引用密钥变量，但真实密钥应放在环境变量或密钥管理服务中，并确认不会被 Git 跟踪。

配置文件和项目规则分别负责什么

配置文件保存运行设置（JSON / YAML / TOML）：用于保存 Provider、模型、地址、端口或权限等运行参数。常见格式有 JSON（严格键值对）、YAML（可写注释）和 TOML（分块清晰）。

项目规则规范协作要求：项目规则用于说明模型在当前项目中需要遵守的要求，例如技术栈、代码风格和协作规范。

修改配置后通常需要重启：多数工具只在启动时读取配置文件。修改 next.config.js、.env 或 tailwind.config.ts 后，通常要重启开发服务器（Ctrl+C 再 npm run dev）才能生效。
