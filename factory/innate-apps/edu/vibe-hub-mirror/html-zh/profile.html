帮我配置两个 Profile：一个叫 work 用我们公司的内网 API，一个叫 personal 用我自己的 API Key，并告诉我怎么切换它们。

按选中的配置工作

Profile 主要隔离配置，不等于新建一个会话；会话和配置是两个不同概念。

Profile 做什么

给配置组起名字：Provider、Base URL、模型和权限等相关参数可以被保存为一个命名组合。

启动时选择一组：启动工具时明确指定 Profile，客户端就按该组参数建立当前会话。

减少手动改错：公司和个人连接各自保存，能减少忘记切换地址或账户后把代码发错地方的风险。

容易混淆的地方

Profile 不是工作区、Git 分支或 Session。它只切换 AI 工具使用的连接参数，不会改变本地文件、提交历史或对话上下文。
