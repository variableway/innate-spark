文件项File

你可能会说

传上来的附件得能看到文件名和大小，还能删掉。

文件项是展示单个文档、图片或附件名称、状态和操作的界面单元·上传完成列表可显示“项目计划.pdf、2.4 MB、已上传”。文件名应最显眼，类型和状态作补充；不能只放一个图标让用户猜文件内容。
也常被叫作文件卡片文件列表项

文件项File≠上传 Upload

文件项 File 展示一个已经存在或待处理的文件；上传 Upload 包含选择、传输和处理文件的完整流程。

什么时候用

  • 已上传附件：让用户确认已选择的文件
    📄项目计划.pdfPDF
  • 项目资料列表：按类型和更新时间浏览文件
    📄项目计划.pdfPDF
  • 聊天中的文件：显示可下载的名称和大小
    📄项目计划.pdfPDF

什么时候不用

  • 尚未选择文件：使用 上传 Upload 提供上传入口
    📄项目计划.pdfPDF
  • 只显示文件图标，未提供可读文件名
    📄项目计划.pdfPDF
  • 将文件状态或删除操作隐藏得难以找到
    📄项目计划.pdfPDF
