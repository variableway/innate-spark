Next.js

你可能会说

我想用 React 做个完整网站，带路由和 SEO，有没有一站式的框架？

Next.js 是基于 React 搭建完整网站的工具，常用于官网、内容站和带登录的网站。·例如用户打开某个商品网址时，它会找到对应详情页，并可先读取商品资料再显示。它不会自动提供商品保存、账号权限等后端能力。

网址怎样找到页面并准备内容

网址对应文件位置：在 App Router 写法里，/posts 对应 app/posts/page.tsx。

服务端准备内容，浏览器负责呈现：页面可以在服务器端先从数据库取数据并拼好 HTML，再交给浏览器显示，减少前端白屏时间。

用 'use client' 区分交互组件：组件默认在服务端运行；需要用户交互（如 onClick、useState）的组件，必须在文件顶部加上 'use client'。如果 AI 写的代码报 “useState only works in Client Components”，通常就是少写了这一行。

容易混淆的地方

同一个 Next.js 项目同时可能有服务器代码和浏览器代码，必须通过 'use client' 明确划分；密钥只能留在不会发送到浏览器的服务器一侧。

选择题选择一个你认为最合适的答案
