服务基准地址Base URL

你可能会说

我把大模型的 API 地址换成我们团队自己部署的中转服务了，现在需要改哪里的 Base URL 才能生效？

Base URL（基准地址）是一组 API 请求共同使用的地址前缀。·例如某个客户端把 https://openrouter.ai/api/v1 与 /chat/completions 拼成完整请求地址。是否包含 /v1、客户端会补哪一段路径，都取决于服务接口和客户端的拼接规则；配置时要同时核对两边的官方文档，不能套用一个固定写法。

同一个服务方可能提供不止一种接口；请先确认工具支持哪种接口，再从官方文档复制地址。

Base URL 的作用机制

用餐厅地址理解 Base URL：把 AI 工具想成帮你点餐的人。Base URL 就像餐厅地址，告诉工具请求应该送到哪里；它不决定使用哪个模型。

去哪里找 Base URL 配置：Codex：~/.codex/config.toml；Claude Code：全局 ~/.claude/settings.json，项目级 .claude/settings.json。如果使用环境变量，再查 ANTHROPIC_BASE_URL。

本地服务也可能有自己的地址：本地模型可能使用 http://localhost:11434/v1，表示请求送到当前电脑；它和 OpenRouter 的地址并不相同。

修改地址后要一起检查什么

排查 Base URL 时，依次确认三件事：请求地址正确、服务支持所填模型、API Key 来自该服务。
