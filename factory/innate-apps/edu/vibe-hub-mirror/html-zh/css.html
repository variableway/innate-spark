CSS 是用规则描述网页外观、布局和不同空间下变化方式的样式语言。·例如 HTML 已经有按钮，但按钮仍是灰色或在手机上挤出页面时，浏览器会根据 CSS 选择器匹配规则，并按优先级和书写顺序算出最终样式。CSS 负责呈现，不负责按钮点击后的业务逻辑。

先看哪些规则匹配：选择器决定一条规则是否作用于这个元素。AI 常在标签上写 class="card" 或 className="card"，CSS 里的 .card 就用来匹配它；像 Tailwind 则是直接把 p-4、flex 等原子类名写在标签上，每个类名对应一条具体样式规则。

再看哪条声明胜出：匹配范围、优先级和书写顺序共同影响结果。开发者工具里的 Styles 和 Computed 面板能显示被覆盖的声明与最后生效的值。

容易混淆的地方

CSS 负责外观、布局和响应式变化；HTML 负责内容结构，JavaScript 负责交互行为。Flex、Grid 和盒模型是 CSS 中的具体布局概念，不需要把整套布局教程重复放在这里。
