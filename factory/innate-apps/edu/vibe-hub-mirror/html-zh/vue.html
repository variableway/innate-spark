Vue 是把网页拆成可复用部分，并让画面跟随数据变化的工具。·例如点一次“+1”后，页面数量从 0 变成 1，Vue 会让按钮旁的文字跟着更新。它只负责页面怎样显示，数据是否长期保存仍要由服务器处理。

ref 里的 count.value 现在是 0

模板里的 {{ count }} 一直读着这个值；ref 变了，文字就同步变。

ref 怎样让模板文字同步变化

ref 放着当前值：ref 可以记住 count 现在是 0 还是 1。

模板正在读取它：按钮里的 {{ count }} 表示：这里显示 count 当前的值。

改值后同步：点击把 count 改掉后，Vue 找到模板里读 count 的位置，换成新的文字。

容易混淆的地方

模板会跟随响应式数据更新；普通变量变化未必触发界面更新，需先确认数据是否由 Vue 管理。
