旅程把产品内外触点放在同一段时间里，并为判断保留证据来源。

用户旅程怎样呈现完整经历

从一个用户和目标开始：明确研究的是哪类用户、什么场景和哪段时间，避免把不同人的经历拼成一条虚假的平均路径。

连接产品内外的触点：社交分享、介绍页、支付、邮件、应用和客服都可能影响同一个目标，不能只记录页面点击。

区分证据与假设：访谈、反馈和行为数据可以支持旅程判断；团队推测需要明确标注并安排验证。

容易混淆的地方

用户旅程 User Journey 跨时间和触点记录行动、想法、感受与证据；用户流程 User Flow 聚焦一个产品目标中的页面、动作和决策分支。两者可以描述同一任务，但回答的问题不同。
