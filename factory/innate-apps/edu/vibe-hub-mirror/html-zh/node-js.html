JavaScript 有两个常见运行地点：浏览器里的页面，和终端里的 Node.js。项目命令、npm 和构建工具都跑在后者上。

Node.js 在整条工具链里的位置

它是运行环境，不是一门新语言：写的还是 JavaScript；Node.js 提供在电脑上执行它的能力，让脚本不打开浏览器也能运行。

构建和包管理工具都依赖它：npm 安装依赖、构建命令、AI 开发工具本身都跑在 Node.js 上。本机没有它，项目命令会直接报 command not found。

版本会被项目要求：项目文档写 requires Node 18+ 时，用 node -v 查看本机版本；版本过低要升级后再运行。

容易混淆的地方

Node.js 不替代浏览器：页面里的交互仍由浏览器执行。它补上的是“离开浏览器也能运行 JavaScript”这一块，命令行工具和服务端程序都靠它。
