页面元数据怎样分工

字段放在 head，结果出现在不同地方：title 影响浏览器标签，description 可能帮助形成搜索摘要，Open Graph 字段服务链接预览，Manifest 描述安装入口。它们都与正文有关，但不是正文内容本身。

按消费方验收实际结果：先问“谁会读这项信息”，再检查字段、资源地址和最终显示。某一处正常，只能证明对应消费者读到了可用信息。

它不是一张万能配置表

页面元数据 Page Metadata 是总类，不会自动替代 页面标题 Title Tag、Open Graph 或 Web 应用清单 Web App Manifest。分享卡缺图时检查分享字段，安装后启动路径错误时检查 Manifest，不要笼统重写正文。
