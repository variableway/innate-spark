HTTP 状态码HTTP Status Code

你可能会说

页面打开是一片 404 页面，是链接写错了还是没部署好？

服务器用三位数字回答一次请求的结果：成功、重定向、请求有问题，还是服务器自己出错·网页打不开或请求失败时，404 代表路径资源不存在，400 代表参数格式未被接受，500 代表服务端内部报错。前端界面上的“加载失败”提示常常语焉不详，开发者工具 Network 面板中的 HTTP 状态码才是快速锁定责任方的第一手证据。

去服务端日志查这次请求，前端提示文字不能替代状态码

选中一行查看它代表什么：首位数字先分大类（2xx 成功、3xx 重定向、4xx 请求有问题、5xx 服务器出错），具体数字再说明原因。

状态码怎样帮助判断该改哪里

先读分类，再读数字：首位数字说明结果类别：2xx 成功、3xx 重定向、4xx 请求有问题、5xx 服务器自己出错。看到 500 就不用先去改前端。

数字进一步说明原因：404 表示没找到对应资源，401 表示身份不被接受，400 表示请求内容不符合约定。同一类别里的差别决定下一步查什么。

去哪里看：浏览器开发者工具的 Network 面板记录每次请求的状态码；接口调试工具和 AI 返回的报错里也会直接给出数字。

容易混淆的地方

状态码说明这次请求的结果，不说明代码有没有 bug。返回 200 也不代表业务正确，例如保存接口成功返回但内容没有写入，仍要按业务结果验收。
