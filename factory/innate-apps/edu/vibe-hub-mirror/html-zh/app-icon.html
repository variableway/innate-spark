App Icon 为什么需要单独适配

系统会改变外框和尺寸：主屏幕、搜索和设置可能使用不同大小或平台形状。源图要在安全区域内保留主要图形，避免系统遮罩后文字和关键轮廓消失。

简化比塞入更多信息更可靠：应用图标承担整体身份识别，小尺寸下应优先保留一个清楚的核心形状。不同平台可以有适配变体，但用户应仍能认出是同一应用。

它不等于 Logo、Favicon 或 UI Icon

应用图标 App Icon 是操作系统识别应用的图像；标志 Logo 是品牌标志；网站图标 Favicon 服务浏览器站点位置；图标 Icon 表达界面功能。可以共享母体，但不能只把横向 Logo 或工具栏图标缩小后直接交付。
