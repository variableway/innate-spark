瀑布流Masonry

你可能会说

图片高矮不一样，别硬裁成一样高，矮的下面自动补上新的就行。

瀑布流是一种保持列对齐、让不同高度的卡片依次补进当前最短列的页面布局·作品墙和灵感流里的图片高度各不相同，瀑布流让新卡片补进最短的空隙，页面不会出现整行留白。代价是阅读顺序按列推进而不是按行；手机端收成单列后，内容顺序需要单独验收。
先知道
卡片 Card网格布局 Grid
也常被叫作瀑布流布局Masonry 布局Masonry Layout
容易混淆？这样区分
瀑布流Masonry≠卡片网格布局 Card Grid

卡片网格布局 Card Grid 保持严格行列对齐、同行等高，适合比较和扫描；瀑布流 Masonry 放弃行对齐换取紧凑，适合以看为主的浏览。

瀑布流Masonry≠Bento 便当格 Bento Grid

Bento 便当格 Bento Grid 用格子大小表达设计好的内容优先级；瀑布流 Masonry 的位置由补位规则自动产生，不表达优先级。

什么时候用

  • 作品墙：摄影、插画比例不一，保持原始比例展示，见 卡片 Card
  • 灵感、素材内容流：强调连续向下浏览，不需要逐行比较
    向下滚动继续加载
  • 商品或案例封面尺寸不统一，又希望页面紧凑
    降噪耳机¥ 899
    护眼台灯¥ 199
  • 纵向空间紧张：内容持续增长，补位比整行留白更省高度

什么时候不用

  • 内容有严格先后顺序（步骤、时间线）：补位会打乱顺序
    步骤 1步骤 2
    步骤 4 排到了步骤 3 前面
  • 需要逐行比较同类信息：列不对齐时比较成本更高，用 卡片网格布局 Card Grid
  • 手机端仍保留多列：卡片被压得过窄，应收成一到两列
  • 把长文列表也塞进瀑布流：阅读顺序混乱，段落难以连续读完
