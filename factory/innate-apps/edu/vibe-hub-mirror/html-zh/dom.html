文档对象模型DOM

你可能会说

点击新增后页面确实多了一条任务，但源 HTML 里找不到它，帮我确认运行时到底插入了什么。

DOM 是浏览器把网页文档表示成可读取和修改的节点树。·例如源 HTML 里只有一个任务，点击“新增”后页面却多出一项，这是脚本创建节点并把它插入运行时 DOM 的结果。DOM 的变化会立即影响当前页面，但刷新后是否还在，取决于有没有另外保存到后端或浏览器存储。

DOM 里新增节点会改变当前页面，但刷新后是否保留取决于有没有真正保存数据。

当前页面为什么会和源文件不同

浏览器先解析文档：浏览器读取 HTML，把文档中的元素、文字和属性组织成节点之间的层级关系，页面据此开始渲染。

脚本可以修改这棵树：点击按钮后，JavaScript 可以创建、删除或修改节点，所以 Elements 面板里的 DOM 可能已经不同于最初的 HTML 文件。

容易混淆的地方

DOM 是浏览器当前页面的运行时文档树，不是初始 HTML 文件，也不是数据库。脚本把任务插入 DOM 后，刷新页面可能消失；要跨刷新、设备或用户保留，仍需另行保存数据。现代前端框架（如 React、Vue）帮你管理 DOM 更新——你描述界面应该长什么样，框架自动算出哪些节点需要变化。AI 生成的 React 代码里很少出现 document.createElement，因为框架在背后替你操作这棵树。
