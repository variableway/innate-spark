上传Upload≠文件项 File

上传 Upload 负责选择、传输和失败重试；文件项 File 展示一个已经存在或正在处理的文件。

什么时候用

  • 拖拽上传：适合大文件或批量选择
    ⬆ 把文件拖到这里，或点击选择
  • 图片上传带预览：头像、封面，传完马上看到
    🖼🖼＋
  • 文件列表 + 进度：多个文件各自的状态清清楚楚
    📄 需求文档.pdf✓
    📄 设计稿.fig66%
  • 写清格式和大小限制：传之前就知道行不行
    ⬆ 点击或拖拽上传
    支持 JPG / PNG，单个不超过 10MB

什么时候不用

  • 用户只有文件链接：使用 输入框 Input 填写 URL
    视频链接⬆ 上传
    用户手里只有一个 URL，给个输入框就行
  • 大量小文件逐个上传：先打包，或支持选择文件夹
    🖼 IMG_001.jpg12 / 38
  • 失败不给重试：传到 99% 失败只能从头再来
    📄 视频素材.mp4✕ 失败
    缺少重试入口，失败后需要重新上传
  • 不设大小上限：1.8GB 传半小时才报错
    🎬 成片-4K.mp4（1.8GB）99%
    传到 99% 才提示超出大小限制
