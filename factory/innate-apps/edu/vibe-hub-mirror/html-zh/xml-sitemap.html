XML Sitemap 负责哪一步

列出想让系统发现的地址：Sitemap 用 XML 组织完整 URL，适合列出网站希望爬虫发现的重要页面。清单里的地址应真实存在、能访问，并与页面选择的规范地址一致。

发现之后仍要请求和判断：爬虫读取清单后还会请求页面，检查能否访问并决定是否继续处理。Sitemap 增加发现机会，不替页面提供内容，也不替搜索系统做收录和排名决定。

容易混淆的地方

XML Sitemap 是给爬虫读取的机器文件；信息架构里的 sitemap 或网站导航是给人理解页面层级的可见结构。它也不是权限控制：公开列出一个 URL 不会授予访问权，未列出也不等于禁止访问。
