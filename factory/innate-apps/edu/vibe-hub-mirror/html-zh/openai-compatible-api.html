OpenAI 兼容 API 解决什么问题

工具按相近格式发请求：工具按照约定的地址和字段发送请求，接入不同的模型服务时，连接方式会更相似。

模型服务负责生成结果：请求送到模型服务后，由它负责处理内容并生成回答。不同服务使用的模型和处理方式可能不同。

每项能力都要单独确认：比如，一个只支持文本的模型，即使接口能接收图片字段，也可能无法识别图片。工具调用、流式返回等功能也要分别测试。

容易混淆的地方

OpenAI 兼容 API 是通信协议层的约定，不是 OpenAI GPT 模型本身。它统一的是通信格式，不等于底层模型拥有 OpenAI 模型的工具调用、多模态或流式能力。
