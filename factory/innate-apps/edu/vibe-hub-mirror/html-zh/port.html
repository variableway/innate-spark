你可能会说

本地项目跑在 3000 端口，接口服务在 4000；帮我确认浏览器连的是哪一个。

端口是同一台主机上区分不同网络服务的编号入口。·例如运行 npm run dev 后常可在 http://localhost:3000 打开网页，同时本机的接口可能监听 4000 端口。localhost 只指当前这台设备；端口让同一台电脑上的多个服务不会混在一起。

端口 3000 把请求送到「网页开发服务」。

地址里的端口负责什么

主机先定位设备：localhost 指向你正在使用的电脑，部署后的域名则定位到可公开访问的服务器；它本身不说明服务是哪一个。

端口再定位服务：冒号后的数字把请求交给对应服务。若开发服务器提示 3001 已被占用或自动换到 3002，浏览器地址也必须随之更新。

容易混淆的地方

端口不是网址域名，也不是“上线开关”。localhost:3000 只能由当前电脑访问；即使端口正确，别人也无法借此打开你的本地项目。端口占用是同一入口冲突，不等同于代码报错。
