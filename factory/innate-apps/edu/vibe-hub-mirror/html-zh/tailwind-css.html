Tailwind CSS 是用一组现成短代码直接写网页外观的工具。·例如 p-6、rounded-xl 和 border 分别表示留白、圆角和边框。短代码很多时，可按留白、文字、边框和布局分组阅读；重复组合应收进同一个可复用界面部分。

类名怎样变成页面样式

直接对应 CSS 属性：每个工具类名就像一句微型指令，直接控制留白、排版等单一属性。例如 p-4 对应内边距 1rem，text-lg 对应较大的字号。

响应式前缀控制断点：通过添加 md:、lg: 或 sm: 前缀，可以指定样式在哪些屏幕尺寸下生效，从而在 HTML 里直接完成响应式设计。

状态变体控制交互：使用 hover:、focus: 或 dark: 变体，可以让元素在特定交互或主题下改变外观，无需写复杂的选择器。

容易混淆的地方

看到很长的一串类名时，先按“留白、文字、边框、布局”分组读；重复出现的整串样式应收进组件。
