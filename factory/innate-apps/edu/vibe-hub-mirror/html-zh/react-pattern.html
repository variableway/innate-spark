ReAct

你可能会说

AI 能不能每完成一步先检查结果，再决定下一步？

ReAct 是让 AI 根据当前证据选择一个操作，读取真实结果，再据此选择下一步的任务方式。·例如登录按钮没有反应时，AI 先检查按钮文件；发现点击事件已经存在后，不再继续修改按钮，而是改查网络请求，并根据 401 结果检查认证信息。

先确认一个具体判断：登录按钮没有反应时，先检查按钮是否绑定点击事件，而不是同时修改多个位置。

读取操作产生的真实结果：文件显示点击事件已经存在，这条证据直接否定了最初判断。

根据结果更换检查方向：按钮点击后出现 401，下一步改查认证信息；这里展示的是任务状态，不是模型的完整内部推理。

容易混淆的地方

ReAct 描述的是“任务级判断 → 行动 → 观察”的交替模式；工具调用只是其中一次行动的表达，Agent 循环则是运行时负责权限、重试、记录和停止条件的控制机制。界面不应声称展示完整内部推理。
