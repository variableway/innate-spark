Plugin 主要扩展宿主工具的能力和界面；它不等同于 MCP 的连接协议或 Skill 的做事方法。

Plugin 做什么

提供编辑器入口：插件可以提供侧边栏、快捷键、行内建议和配置界面。

收集当前上下文：用户选中代码后，插件可以把文件和语言等上下文发给模型，并在编辑器里展示结果。

让修改可预览：代码 diff 预览让用户先比较修改，再决定是否接受写回文件。

容易混淆的地方

Plugin 是可安装的软件组件，Skill 是可复用的任务方法，Hook 是事件触发的后台命令。插件改善交互和集成，不保证模型生成的代码没有 Bug。
