# innate-vivid

可交互、可执行的教学项目集合。

## 主要目标

- 构建**可交互的教学网站**，并且内容**可以执行**：不是只读文档，而是能点、能跑、能立刻看到效果。
- 一切从简：**简单、可运行、能看到效果**，是这个目录里所有项目共同的底线。

## 当前项目

| 项目 | 形态 | 说明 |
| --- | --- | --- |
| [reset-from-zero](./reset-from-zero) | 教程与文档 | 记录教程和实践的文档，一般从问题出发：先有一个问题，再展开实践和解答。 |
| [innate-executable](./innate-executable) | 可执行应用 | 基于 Next.js + Tauri 的学习平台，教程内嵌可运行代码块，coding 或一些设置可以直接执行，在内嵌终端里看到结果。 |

两个项目分工：reset-from-zero 负责"讲清楚"，innate-executable 负责"跑起来"。
